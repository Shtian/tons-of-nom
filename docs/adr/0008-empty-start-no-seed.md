# ADR 0008 — Empty start, no seed list

**Status:** Accepted
**Date:** 2026-06-24

## Context
"Add missing stalls" implied a pre-seeded list. Asked whether the organizer pre-loads known stalls or the site starts empty.

## Decision
**Start empty.** No seed data. The first visitors create the stalls; the list is fully crowd-built.

## Consequences
- No data-entry work before the event.
- Day-one experience is a near-empty list — first users must add before they can rate. Onboarding copy should make "add a stall" obvious when the list is empty.
- Higher early duplicate risk (nothing to search against yet) — accepted (ADR 0007).
